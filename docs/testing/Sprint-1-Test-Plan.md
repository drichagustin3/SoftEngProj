# Sprint 1 Test Plan

## Feature: User Registration

### Test Case: TC-REG-001

**Objective:** Verify that a new user can register successfully.

**Preconditions:**
- The registration page is accessible.
- The user does not already have an account.

**Test Steps:**
1. Open the registration page.
2. Enter a valid name.
3. Enter a valid email address.
4. Enter the required information.
5. Click the Register button.

**Expected Result:**
- The system successfully creates the account.
- The account status is set to Pending.
- A confirmation message is displayed.

**Test Type:** Positive Testing
